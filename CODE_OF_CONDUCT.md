# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Resumen

- Trata a todas las personas con respeto, sin importar su experiencia, edad, género, origen o creencias.
- Critica las ideas y el código, nunca a las personas.
- Acepta las correcciones con buena disposición y reconoce los errores propios.
- No se tolera el acoso, los insultos ni la publicación de datos personales de otras personas.

Esta app es para niñas y niños: cuida especialmente que ningún contenido, ejemplo o dato de prueba sea
inapropiado para su edad.

## Aplicación

El responsable del proyecto decide sobre cualquier incidente. Los avisos se envían de forma privada desde la
pestaña **Security** del repositorio y se tratan con confidencialidad.
